## 📖 О проекте
 
**Catai** — ИИ-помощник, рассчитанный на локальное использование. Он сначала ищет ответ в вашей базе знаний, а если ответа там нет, обращается к интернету.
 
Основные возможности:
 
- 🧠 работа с локальным файлом `knowledge.txt`;
- 🌐 поиск дополнительной информации в интернете через Wikipedia и DuckDuckGo;
- 💬 диалоговый интерфейс и история сообщений;
- 🧹 очистка истории диалога;
- 😼 собственный характер и немного самоиронии.
> ⚠️ Проект находится в стадии беты: возможны ошибки и неточные ответы.
 
### 🔐 Приватность
 
| Что | Где обрабатывается |
| --- | --- |
| Файл `knowledge.txt` | Хранится на вашем компьютере |
| Вопросы, ответа на которые нет в базе знаний | Текст запроса отправляется в Wikipedia и DuckDuckGo |
 
Поэтому слова «полностью локально» относятся к базе знаний, но не к сетевым запросам.
 
Не добавляйте в `knowledge.txt` пароли, токены и персональные данные. Если ответа в базе нет, текст вашего вопроса отправляется во внешние сервисы поиска, поэтому не задавайте в таком случае вопросов с конфиденциальной информацией.

## 📥 Установка
 
### Через winget (рекомендуется)
 
Самый быстрый способ — установить Catai через встроенный менеджер пакетов Windows.
 
Откройте **PowerShell** или **Терминал** и выполните:
 
```powershell
winget install Kirill638849776.CatAI
```
 
Обновление до новой версии:
 
```powershell
winget upgrade Kirill638849776.CatAI
```
 
### Вручную из Releases
 
1. Откройте раздел [Releases](https://github.com/Kirill638849776/catai/releases).
2. Скачайте последнюю версию `catai_beta.exe`.
3. Положите файл в удобную папку.
Чтобы убедиться, что файл не повреждён, сравните его SHA256-хэш с хэшем в описании релиза:
 
```powershell
Get-FileHash .\catai_beta.exe -Algorithm SHA256
```
 
Windows SmartScreen может показать предупреждение для малоизвестных программ. Если вы доверяете источнику, нажмите «Подробнее» → «Выполнить в любом случае».

## 🛠️ Команды
 
| Команда | Что делает |
| --- | --- |
| `/info` | Показывает информацию о боте |
| `/clear` | Очищает историю диалога |
| `/history` | Показывает последние 10 сообщений |
| `/exit` или `выход` | Выход из программы |
