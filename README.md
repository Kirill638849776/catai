## 📖 О проекте

**Catai** — это ИИ-помощник, который:
- ✅ Отвечает на вопросы из вашего файла `knowledge.txt`
- ✅ Ищет ответы в интернете (Wikipedia, DuckDuckGo)
- ✅ Работает полностью локально
- ✅ Не отправляет ваши данные в облако
- ✅ Имеет характер и самоиронию (бета-версия!)

## 🚀 Запуск

1. Скачайте `catai_beta.exe`
2. Поместите в ту же папку файл `knowledge.txt` (с вашей базой знаний)
3. Запустите `catai_beta.exe`
4. Начните диалог!

---

## 🛠️ Команды

| Команда | Что делает |
|---|---|
| `/info` | Показывает информацию о боте |
| `/clear` | Очищает историю диалога |
| `/history` | Показывает последние 10 сообщений |
| `/exit` или `выход` | Выход из программы |
